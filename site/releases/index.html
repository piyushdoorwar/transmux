Downloads and installation

Download any release of Transmux: a Debian package for Ubuntu and Debian, and an installer for Windows. Stable builds are listed by default.

Ubuntu PPA

Add the PPA for automatic updates.

$ sudo add-apt-repository ppa:piyushdoorwar/transmux
$ sudo apt update
$ sudo apt install transmux

Direct .deb install

Download the .deb below, then install it. Requires ffmpeg, installed with sudo apt install ffmpeg.

$ sudo apt install ~/Downloads/transmux_*.deb

Windows installer

Download the .exe installer below and run it. FFmpeg is bundled, so no additional setup is needed.
